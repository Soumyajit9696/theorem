Theorem — LaTeX to PNG converter & LaTeX equation image generator

Theorem is a free online tool that converts LaTeX to PNG, SVG, JPG and vector-PDF images. Type or paste LaTeX, watch it render live, then export equations with transparent backgrounds, custom ink colors, padding and corner radius. Supports LaTeX environments (equation, align, cases, matrices, arrays), inline autocomplete, 40+ formula templates and a full command reference — all client-side, no signup.

Built by Soumyajit Das · github.com/Soumyajit9696/theorem

What's inside

  • Live typesetting via MathJax 3 (SVG output) — nothing leaves your browser.
  • Inline LaTeX autocomplete: type \ and a few letters, Tab completes — environment skeletons included.
  • Full environment support: equation, align, gather, cases, split, matrices, arrays — pasted fragments with delimiters, labels, comments and even \documentclass are understood.
  • 40+ ready-made templates and a searchable reference of ~160 commands, all with live previews.
  • Ink, size, background, padding & corner controls — plus a separate selection color for highlighting parts of an equation.
  • Exports: PNG / JPG at 1–6×, standalone SVG, vector PDF (jsPDF + svg2pdf, loaded only when needed).
  • Clipboard: copy the rendered PNG, the SVG markup, the LaTeX source, a base64 data URI — or a share link that carries the equation in the URL.
  • Open and save .tex files — drag one straight onto the editor.
  • Light & dark themes, persistent render history, and settings remembered locally.

Notes

Everything runs locally; only MathJax, the fonts and — on PDF export — jsPDF load from a CDN. Your input and settings stay in this browser's localStorage. JPEG has no alpha channel, so transparent backgrounds are filled white. PDFs are true vector when svg2pdf is available, otherwise rasterized at export scale.
